## 📚 Sobre o projeto

Este portfólio foi desenvolvido como um projeto pessoal para reunir e apresentar meus principais trabalhos, experiências de aprendizado e conhecimentos em tecnologia.

A proposta também foi criar uma identidade visual que representasse minha personalidade, combinando **tecnologia e criatividade**.

Durante o desenvolvimento, busquei aplicar na prática conceitos de HTML, CSS e JavaScript, além de explorar organização de layout, responsividade, interações e experiência do usuário.

## 🎯 Objetivo

Criar um espaço para apresentar minha evolução na área de tecnologia, meus projetos e conhecimentos, além de facilitar o contato com pessoas interessadas no meu trabalho.

O portfólio continuará sendo atualizado conforme eu desenvolver novos projetos e adquirir novos conhecimentos.

## 🧠 O que pratiquei

- Estruturação de páginas com HTML
- Estilização e organização de layouts com CSS
- Interações e funcionalidades com JavaScript
- Responsividade
- Manipulação de elementos da página
- Navegação entre seções
- Implementação de modo claro e escuro
- Organização de projetos web
- Experiência e interface do usuário

## 🚀 Aprendizado

O desenvolvimento deste projeto foi uma oportunidade de colocar em prática conhecimentos adquiridos durante meus estudos e também de experimentar diferentes ideias de design e desenvolvimento.

Além de funcionar como meu portfólio, este projeto representa parte da minha evolução na área de tecnologia e continuará sendo aprimorado ao longo da minha jornada.
